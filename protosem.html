ProtoSem Journal

My weekly learning journal

A week-by-week record of everything I learn during ProtoSem — topics covered, key takeaways and personal reflections. A new card is added every week.

Week 0

July 2026

Orientation, 16 Personalities & Zen Pencils

The programme began with an orientation session that explained the structure, goals and expectations of ProtoSem. I completed the 16 Personalities assessment to understand my own working style, and explored Zen Pencils comics that translate inspiring quotes into visual stories about persistence and purpose.

Topics Learned

  • ProtoSem orientation — structure, outcomes and weekly workflow
  • 16 Personalities (MBTI-style) assessment and result interpretation
  • Understanding personality traits: mind, energy, nature, tactics, identity
  • Zen Pencils — storytelling through illustrated quotes

Key Takeaways

  • Knowing my personality type helps me choose how I study and collaborate
  • Self-awareness is the first step before skill-building
  • Visual storytelling makes abstract ideas memorable and motivating

Resources Used

  • 16personalities.com — free personality assessment
  • zenpencils.com — illustrated quote comics

Reflection

Starting with self-understanding rather than technical content was unexpected but valuable. Reading my personality result explained why I prefer planning before acting, and the Zen Pencils stories reminded me that consistency matters more than talent. I want to carry this mindset into every following week.

Week 1

July 2026

5S Framework & Building My Portfolio

This week focused on workplace discipline and personal branding. I studied the 5S framework used in industry to organise workspaces, and then started building my own personal portfolio website to present my skills, projects and progress in one place.

Topics Learned

  • 5S framework — Sort, Set in order, Shine, Standardise, Sustain
  • Applying 5S to a lab bench, a desk and even to digital files
  • Portfolio structure — home, about, skills, experience and contact
  • Basics of clean layout, typography and responsive design

Key Takeaways

  • An organised workspace directly reduces wasted time and mistakes
  • Standardising is what makes improvement stick — not one-time cleaning
  • A portfolio is a living document; it should grow with every project

Resources Used

  • 5S lean methodology handouts and case studies
  • MDN Web Docs — HTML and CSS fundamentals

Reflection

I realised that 5S is not only a factory practice — applying "Sort" and "Set in order" to my own folders and notes made studying noticeably faster. Building the portfolio pushed me to describe my work clearly, which will help in interviews and applications later.

Week 2

August 2026

Algorithms, Flowcharts, Python, Scratch & MIT App Inventor

A hands-on computational thinking week. I learned to break problems into step-by-step algorithms, represent them as flowcharts, then implement the same logic in Python, visually in Scratch, and finally as a working mobile app in MIT App Inventor.

Topics Learned

  • Algorithms — sequence, selection, iteration and pseudocode
  • Flowcharts — standard symbols, decision branches and loops
  • Python — variables, conditionals, loops, functions and lists
  • Scratch — block-based programming, sprites, events and logic
  • MIT App Inventor — designer view, blocks editor and app testing

Key Takeaways

  • Designing the flowchart first makes coding far faster and less buggy
  • The same logic transfers across languages — only the syntax changes
  • Block-based tools like Scratch and App Inventor make logic visible
  • Building an actual app made programming feel practical, not theoretical

Resources Used

  • Python official documentation and practice exercises
  • scratch.mit.edu — block programming environment
  • appinventor.mit.edu — mobile app builder

Reflection

This was the week where things clicked. Writing a flowchart before code changed how I approach problems — I now plan the logic on paper first. Seeing my Python logic work the same way in Scratch and then run on a phone through App Inventor showed me that programming is really about clear thinking, and that will help me in automation and embedded projects ahead.
