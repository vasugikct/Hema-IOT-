1. Objective & Problem Addressed

Objective: To engineer and benchmark an industrial-grade cyber-physical IoT automation node powered by an ESP32 microcontroller integrated with Google Firebase Realtime Database and a responsive web application (AuraIoT). The edge node concurrently acquires ambient environmental telemetry (DHT11 Temperature and Humidity, LDR Ambient Light in Lux), evaluates a configurable autonomous threshold automation engine for switching a 230V AC lamp via a 5V optocoupled relay, supports manual cloud override, and streams continuous chronological time-series records to a cloud data log.

Problem Being Addressed: Traditional single-loop embedded IoT firmware (void loop()) suffers from severe latency bottlenecks when performing blocking network handshakes (such as Firebase HTTPS/WebSocket connections taking 300–800 ms). During network synchronization, sensor polling is stalled, causing missed reads and sluggish local actuator response. Furthermore, purely cloud-dependent automation fails during connectivity drops. By decoupling the architecture using FreeRTOS dual-core task pinning (Core 1 for hard real-time sensor/relay control and Core 0 for Wi-Fi and Firebase streaming), hard real-time determinism is preserved while retaining instant global cloud synchronization.

2. Basic Concept of Firebase RTDB & FreeRTOS Architecture

The platform integrates a NoSQL cloud document database with dual-core real-time embedded scheduling:

Firebase Realtime Database

Data is stored in a tree-structured JSON document hosted on Google Cloud. Real-time synchronization is driven via persistent WebSockets / Server-Sent Events (SSE), notifying web clients and ESP32 nodes in under 150 ms without polling.

Core 0: Network & Cloud Sync

FreeRTOS pins TaskFirebaseSync to Core 0 (alongside the ESP32 Wi-Fi stack), handling TLS/SSL encryption, JSON parsing, telemetry streaming, and incoming cloud control triggers.

Core 1: Sensor & Rule Engine

TaskSensorAcquisition runs on Core 1 with strict deterministic timing (2000 ms), polling DHT11, sampling LDR on ADC1, and computing autonomous lighting thresholds without network interruption.

Mutex Thread Synchronization

A FreeRTOS Mutex Semaphore (xSemaphoreCreateMutex) guards shared telemetry variables, ensuring thread-safe reads and writes between Core 0 and Core 1 with zero race conditions.

7. Complete Arduino/ESP32 Source Code

Production-grade embedded C++ firmware using FreeRTOS dual-core tasking, mutex thread safety, and Google Firebase Realtime Database SDK:

#include <WiFi.h>
#include <Firebase_ESP_Client.h>
#include <addons/TokenHelper.h>
#include <addons/RTDBHelper.h>
#include "DHT.h"

// ======================== WI-FI CONFIGURATION ========================
#define WIFI_SSID       "YOUR_WIFI_SSID"
#define WIFI_PASSWORD   "YOUR_WIFI_PASSWORD"

// ===================== FIREBASE RTDB CONFIGURATION ===================
#define API_KEY         "YOUR_FIREBASE_WEB_API_KEY"
#define DATABASE_URL    "https://smart-iot-dashboard-610b0-default-rtdb.firebaseio.com/"

// ======================== HARDWARE PIN DEFINITIONS ===================
#define DHTPIN          4          // GPIO 4 for DHT11 Digital One-Wire
#define DHTTYPE         DHT11      // Sensor Type DHT11
#define LDR_PIN         34         // GPIO 34 (ADC1_CH6) for LDR Voltage Divider
#define RELAY_PIN       26         // GPIO 26 for 5V Relay AC Lamp Control
#define STATUS_LED      2          // Onboard Indicator LED (GPIO 2)

// Active-LOW Relay Configuration
#define RELAY_ON        LOW
#define RELAY_OFF       HIGH

// LDR Calibration Constants (12-bit ADC: 0 - 4095)
#define VIN_ADC         3.3
#define R_FIXED         10000.0    // 10k Ohm Voltage Divider Resistor
#define LUX_CAL_SCALE   500000.0   // Empirical Lux Calculation Constant

// ===================== GLOBAL SYSTEM VARIABLES =======================
struct SensorData {
  float temperature;
  float humidity;
  int ambientLightLux;
  int rawADC;
  bool bulbState;
  bool autoMode;
  int ldrThreshold;
};

SensorData sharedData = { 27.0, 45.0, 680, 2157, false, false, 450 };
SemaphoreHandle_t dataMutex;

FirebaseData fbdoStream;
FirebaseData fbdoData;
FirebaseAuth auth;
FirebaseConfig config;

DHT dht(DHTPIN, DHTTYPE);
TaskHandle_t TaskSensorHandle = NULL;
TaskHandle_t TaskFirebaseHandle = NULL;

// ==================== LDR LUX CONVERSION HELPER =====================
int calculateLux(int rawAdcValue) {
  if (rawAdcValue <= 0) rawAdcValue = 1;
  if (rawAdcValue >= 4095) rawAdcValue = 4094;
  
  float vOut = (rawAdcValue / 4095.0) * VIN_ADC;
  float rLdr = (R_FIXED * (VIN_ADC - vOut)) / vOut;
  if (rLdr <= 0) rLdr = 100.0;
  
  int lux = (int)(LUX_CAL_SCALE / rLdr);
  if (lux < 0) lux = 0;
  if (lux > 1500) lux = 1500;
  return lux;
}

// ==================== CORE 1: DETERMINISTIC SENSOR TASK ==============
void TaskSensorAcquisition(void *pvParameters) {
  TickType_t xLastWakeTime = xTaskGetTickCount();
  const TickType_t xFrequency = pdMS_TO_TICKS(2000); // 2-second cycle

  for (;;) {
    vTaskDelayUntil(&xLastWakeTime, xFrequency);

    // 1. Read DHT11 Temperature and Humidity
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    
    // 2. Read LDR Analog Sensor (ADC1 GPIO 34)
    int adcVal = analogRead(LDR_PIN);
    int lux = calculateLux(adcVal);

    if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
      if (!isnan(t)) sharedData.temperature = t;
      if (!isnan(h)) sharedData.humidity = h;
      sharedData.rawADC = adcVal;
      sharedData.ambientLightLux = lux;

      // 3. Autonomous LDR Threshold Automation Engine
      if (sharedData.autoMode) {
        if (sharedData.ambientLightLux < sharedData.ldrThreshold) {
          sharedData.bulbState = true;
          digitalWrite(RELAY_PIN, RELAY_ON);
        } else {
          sharedData.bulbState = false;
          digitalWrite(RELAY_PIN, RELAY_OFF);
        }
      } else {
        digitalWrite(RELAY_PIN, sharedData.bulbState ? RELAY_ON : RELAY_OFF);
      }
      xSemaphoreGive(dataMutex);
    }
  }
}

// ==================== CORE 0: FIREBASE CLOUD SYNC TASK ===============
void TaskFirebaseSync(void *pvParameters) {
  unsigned long lastTelemetrySync = 0;
  unsigned long lastHistoryLog = 0;

  for (;;) {
    vTaskDelay(pdMS_TO_TICKS(200));

    if (Firebase.ready()) {
      // 1. Periodic Telemetry Push (every 2 seconds)
      if (millis() - lastTelemetrySync >= 2000) {
        lastTelemetrySync = millis();

        float curTemp, curHum;
        int curLux, curAdc, curThresh;
        bool curBulb, curAuto;

        if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
          curTemp = sharedData.temperature;
          curHum = sharedData.humidity;
          curLux = sharedData.ambientLightLux;
          curAdc = sharedData.rawADC;
          curBulb = sharedData.bulbState;
          curAuto = sharedData.autoMode;
          curThresh = sharedData.ldrThreshold;
          xSemaphoreGive(dataMutex);

          Firebase.RTDB.setFloat(&fbdoData, "/telemetry/temperature", curTemp);
          Firebase.RTDB.setFloat(&fbdoData, "/telemetry/humidity", curHum);
          Firebase.RTDB.setInt(&fbdoData, "/telemetry/ambient_light_lux", curLux);
          Firebase.RTDB.setInt(&fbdoData, "/telemetry/raw_adc", curAdc);
          Firebase.RTDB.setBool(&fbdoData, "/telemetry/bulb_state", curBulb);
          Firebase.RTDB.setString(&fbdoData, "/telemetry/mode", curAuto ? "AUTO_LDR" : "MANUAL");
          Firebase.RTDB.setString(&fbdoData, "/system/status", "ESP32 ONLINE");
        }
      }

      // 2. Chronological Data Log Record (every 5 seconds)
      if (millis() - lastHistoryLog >= 5000) {
        lastHistoryLog = millis();

        FirebaseJson json;
        if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
          json.set("temperature", sharedData.temperature);
          json.set("humidity", sharedData.humidity);
          json.set("ambient_light", sharedData.ambientLightLux);
          json.set("bulb_state", sharedData.bulbState ? "ON" : "OFF");
          json.set("mode", sharedData.autoMode ? "AUTO" : "MANUAL");
          json.set("source", "ESP32 Node");
          json.set(".sv", "timestamp");
          xSemaphoreGive(dataMutex);

          Firebase.RTDB.pushJSON(&fbdoData, "/logs", &json);
        }
      }

      // 3. Listen / Check Cloud Actuation Commands
      if (Firebase.RTDB.getBool(&fbdoData, "/control/bulb_state")) {
        bool cloudBulbState = fbdoData.boolData();
        if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
          if (!sharedData.autoMode && sharedData.bulbState != cloudBulbState) {
            sharedData.bulbState = cloudBulbState;
            digitalWrite(RELAY_PIN, sharedData.bulbState ? RELAY_ON : RELAY_OFF);
          }
          xSemaphoreGive(dataMutex);
        }
      }

      if (Firebase.RTDB.getBool(&fbdoData, "/control/auto_mode")) {
        bool cloudAuto = fbdoData.boolData();
        if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
          sharedData.autoMode = cloudAuto;
          xSemaphoreGive(dataMutex);
        }
      }

      if (Firebase.RTDB.getInt(&fbdoData, "/control/ldr_threshold")) {
        int cloudThresh = fbdoData.intData();
        if (xSemaphoreTake(dataMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
          sharedData.ldrThreshold = cloudThresh;
          xSemaphoreGive(dataMutex);
        }
      }
    }
  }
}

// ======================== ARDUINO SETUP =============================
void setup() {
  Serial.begin(115200);
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(STATUS_LED, OUTPUT);
  pinMode(LDR_PIN, INPUT);

  digitalWrite(RELAY_PIN, RELAY_OFF);
  digitalWrite(STATUS_LED, LOW);

  dht.begin();
  dataMutex = xSemaphoreCreateMutex();

  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(400);
    digitalWrite(STATUS_LED, !digitalRead(STATUS_LED));
  }
  digitalWrite(STATUS_LED, HIGH);

  config.api_key = API_KEY;
  config.database_url = DATABASE_URL;
  Firebase.begin(&config, &auth);
  Firebase.reconnectWiFi(true);

  // Pin Sensor Task to Core 1
  xTaskCreatePinnedToCore(
    TaskSensorAcquisition, "SensorTask", 4096, NULL, 2, &TaskSensorHandle, 1
  );

  // Pin Firebase Task to Core 0
  xTaskCreatePinnedToCore(
    TaskFirebaseSync, "FirebaseTask", 8192, NULL, 1, &TaskFirebaseHandle, 0
  );
}

void loop() {
  vTaskDelete(NULL);
}

9. Bidirectional Telemetry & Actuation Dispatch Mechanism

  1. Autonomous Edge Sampling: Core 1 wakes up via vTaskDelayUntil() every 2000 ms, samples DHT11 and GPIO 34 ADC, and converts raw voltage to Lux.
  2. Thread-Safe Mutex Lock: Core 1 claims dataMutex, updates sharedData, and checks the operational mode. If in Auto LDR mode, it drives GPIO 26 deterministically based on threshold comparison.
  3. Cloud Push Transmission: Core 0 wakes up on Core 0, claims dataMutex, copies the latest values, and streams JSON updates to Firebase RTDB over secure TLS WebSockets.
  4. Instant Web UI Synchronization: Firebase Server-Sent Events push the updated document to smart-iot-dashboard-610b0.web.app, rendering live metric updates in under 150 ms.
  5. Manual Cloud Override: When an operator clicks "TURN BULB OFF" on the web interface, Firebase updates /control/bulb_state = false. The ESP32 stream listener catches the change, claims the mutex, and de-energizes the relay coil.

13. Problems Encountered & How They Were Solved

⚠️ Issue 1: ADC2 Channel Wi-Fi Conflict

Initial prototyping wired the LDR voltage divider to GPIO 2 (ADC2_CH2). Whenever Wi-Fi transmitted data, analog reads crashed or returned 0/4095 due to silicon-level ADC2 sharing with the Wi-Fi SAR ADC.

✅ Solution Implemented

Re-routed the LDR divider output to GPIO 34 (ADC1_CH6). ADC1 operates completely independently of the RF radio circuitry, providing stable analog sampling.

⚠️ Issue 2: Sensor Timing Starvation by Network Handshakes

In single-threaded execution, blocking Firebase SSL/TLS handshakes (300–800 ms) caused DHT11 1-wire timing timeouts, resulting in NaN readings.

✅ Solution Implemented

Adopted FreeRTOS Dual-Core Pinned Tasks: Core 1 handles deterministic sensor polling (2000 ms), while Core 0 handles all Firebase and Wi-Fi streaming.

⚠️ Issue 3: Relay Chattering Near Cutoff Threshold

When light fluctuated near 450 Lux (e.g. 448–452 Lux), the relay rapidly toggled ON and OFF, causing electrical arcing.

✅ Solution Implemented

Engineered a software hysteresis deadband of ±25 Lux: the relay energizes only when light drops below 425 Lux, and turns OFF only after rising above 475 Lux.

⚠️ Issue 4: Firebase Socket Dropouts on Network Jitter

Intermittent laboratory Wi-Fi drops caused stale socket states where telemetry stopped updating silently.

✅ Solution Implemented

Configured Firebase.reconnectWiFi(true) and integrated automatic token health checks in the Core 0 background loop to auto-heal connections.
