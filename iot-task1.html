1. Objective & Problem Addressed

Objective: To develop and validate an embedded standalone HTTP web server executing on an ESP32 SoC connected to a local Wi-Fi intranet. The server hosts a lightweight, responsive HTML user interface capable of dispatching commands to toggle a physical Light Emitting Diode (LED) on and off in real time with zero external cloud dependencies.

Problem Being Addressed: Traditional manual switches limit physical accessibility in enclosed or hazardous setups, while third-party commercial cloud solutions introduce latency, recurrent subscription costs, and internet dependency. Running an edge web server directly on the microcontroller delivers instantaneous local control with complete privacy and offline reliability.

2. Basic Concept of an ESP32 Web Server

The ESP32 incorporates a dual-core 32-bit Xtensa LX6 microprocessor with integrated 2.4 GHz Wi-Fi baseband:

  • Station (STA) Mode: The ESP32 associates with an existing Wi-Fi Access Point using WPA2-PSK and obtains an IPv4 address via DHCP.
  • TCP Socket Daemon: A WiFiServer object listens on standard HTTP port 80 for incoming TCP connection requests.
  • Socket Processing: When an HTTP client sends a request, the server parses the request string, toggles GPIO 2 accordingly, and returns an HTTP 200 OK header with the refreshed HTML document.

3. How ESP32 and Browser Communicate over Wi-Fi

The system operates on the classic Client-Server Request-Response model over TCP/IP:

Phase Source Destination Protocol Action
1. Network Join ESP32 Wi-Fi Router Negotiates DHCP lease (e.g. 192.168.1.105) and initializes Port 80 socket.
2. Client Request Browser ESP32 Transmits HTTP GET line: GET /H HTTP/1.1\r\n upon user click.
3. Header Parsing ESP32 Internal Logic Buffers stream; detects GET /H or GET /L.
4. Actuation ESP32 GPIO 2 Pin Calls digitalWrite(2, HIGH); forward biases LED with 3.3V.
5. Response Flush ESP32 Browser Streams HTTP/1.1 200 OK headers and updated HTML payload.

7. Complete Arduino/ESP32 Source Code

task1_esp32_webserver_led.ino — Arduino C++ 
/*
  =============================================================================
  Project     : ESP32 Web Server & HTML LED Control (IoT Task 1)
  Author      : Vasugi D (B.E. Mechatronics Engineering, KCT)
  Description : Standalone HTTP Web Server running on ESP32 to remotely control
                an LED actuator over a local Wi-Fi intranet.
  Hardware    : ESP32 DevKit V1, 5mm LED, 220 Ohm Resistor, Breadboard
  Pin Wiring  : GPIO 2 -> 220 Ohm Resistor -> LED Anode (+) | LED Cathode (-) -> GND
  =============================================================================
*/

#include <WiFi.h>

const char* ssid     = "YOUR_WIFI_SSID";     // Local Wi-Fi SSID
const char* password = "YOUR_WIFI_PASSWORD"; // Local Wi-Fi Password

WiFiServer server(80); // Bind server to HTTP port 80
const int ledPin = 2;  // GPIO 2

String ledState = "OFF";
String header;

unsigned long currentTime = millis();
unsigned long previousTime = 0;
const long timeoutTime = 2000;

void setup() {
  Serial.begin(115200);
  delay(100);

  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, LOW);

  Serial.print("[Wi-Fi] Connecting to ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("[Wi-Fi] Connected successfully!");
  Serial.print("[Wi-Fi] Server IP: http://");
  Serial.println(WiFi.localIP());

  server.begin();
}

void loop() {
  WiFiClient client = server.available();

  if (client) {
    currentTime = millis();
    previousTime = currentTime;
    String currentLine = "";

    while (client.connected() && currentTime - previousTime <= timeoutTime) {
      currentTime = millis();
      if (client.available()) {
        char c = client.read();
        header += c;

        if (c == '\n') {
          if (currentLine.length() == 0) {
            client.println("HTTP/1.1 200 OK");
            client.println("Content-type:text/html");
            client.println("Connection: close");
            client.println();

            if (header.indexOf("GET /H") >= 0) {
              ledState = "ON";
              digitalWrite(ledPin, HIGH);
            } else if (header.indexOf("GET /L") >= 0) {
              ledState = "OFF";
              digitalWrite(ledPin, LOW);
            }

            client.println("<!DOCTYPE html><html>");
            client.println("<head><meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">");
            client.println("<link rel=\"icon\" href=\"data:,\">");
            client.println("<style>");
            client.println("html { font-family: sans-serif; text-align: center; background: #070e17; color: #e8eef4; }");
            client.println("body { margin: 0; padding: 2rem 1rem; display: flex; flex-direction: column; align-items: center; justify-content: center; min-height: 90vh; }");
            client.println(".card { background: #0e1b29; border: 1px solid rgba(255,255,255,0.1); border-radius: 20px; padding: 2.2rem; max-width: 420px; width: 100%; box-shadow: 0 20px 40px rgba(0,0,0,0.5); }");
            client.println("h1 { font-size: 1.8rem; margin: 0 0 0.5rem; color: #4a9ee8; }");
            client.println(".status-box { background: rgba(255,255,255,0.04); border-radius: 12px; padding: 1rem; margin-bottom: 2rem; }");
            client.println(".state-on { color: #3dcc8e; font-weight: bold; font-size: 1.3rem; }");
            client.println(".state-off { color: #e85a5a; font-weight: bold; font-size: 1.3rem; }");
            client.println(".btn { display: inline-block; width: 100%; box-sizing: border-box; text-decoration: none; padding: 16px; font-size: 1.1rem; font-weight: 600; border-radius: 12px; margin-bottom: 12px; }");
            client.println(".btn-on { background: #3dcc8e; color: #04121a; }");
            client.println(".btn-off { background: #e85a5a; color: #fff; }");
            client.println("</style></head>");
            
            client.println("<body><div class=\"card\">");
            client.println("<h1>ESP32 LED Controller</h1>");
            client.println("<p style=\"color:#93a5b5; margin-bottom:1.5rem;\">Vasugi D · IoT Task 1</p>");
            
            client.println("<div class=\"status-box\">");
            client.print("<p style=\"margin:0 0 6px; font-size:0.85rem; color:#93a5b5;\">CURRENT LED STATE</p>");
            if (ledState == "ON") {
              client.println("<span class=\"state-on\">ON</span>");
            } else {
              client.println("<span class=\"state-off\">OFF</span>");
            }
            client.println("</div>");

            client.println("<a href=\"/H\" class=\"btn btn-on\">TURN ON LED</a>");
            client.println("<a href=\"/L\" class=\"btn btn-off\">TURN OFF LED</a>");
            client.println("</div></body></html>");

            client.println();
            break;
          } else {
            currentLine = "";
          }
        } else if (c != '\r') {
          currentLine += c;
        }
      }
    }

    header = "";
    client.stop();
  }
}

9. How the Webpage Sends a Command to the ESP32

  1. User clicks the <a href="/H"> button.
  2. Browser sends an HTTP request header: GET /H HTTP/1.1.
  3. ESP32 firmware evaluates header.indexOf("GET /H") >= 0.
  4. Firmware executes digitalWrite(ledPin, HIGH) and updates state.
  5. Firmware returns HTTP/1.1 200 OK with updated HTML displaying state ON.

13. Problems Encountered & How They Were Solved

⚠️ Issue 1: DHCP Dynamic IP Drift

Router lease renewal changed the ESP32 IP address after reboot.

✅ Solution Implemented

Enabled Serial Monitor IP reporting at 115200 baud and prepared static IP binding configuration.

⚠️ Issue 2: Favicon Request Interference

Browser sent requests for /favicon.ico causing false command parses.

✅ Solution Implemented

Injected <link rel="icon" href="data:,"> into HTML head to suppress favicon queries.

⚠️ Issue 3: Socket Hang on Client Disconnect

Sudden client disconnects caused ESP32 to hang in while loop.

✅ Solution Implemented

Implemented a 2000 ms timeout guard with millis() and forced client.stop().

⚠️ Issue 4: Strapping Pin Selection

Certain pins interrupted bootloader flashing.

✅ Solution Implemented

Selected GPIO 2, which has reliable post-boot output behavior.

14. Reflection on What I Learned

  • Protocol Fundamentals: Parsing raw HTTP GET headers character-by-character demystified how embedded microcontrollers connect to modern web clients.
  • Memory-Efficient Firmware: Balancing HTML generation within tight microcontroller RAM limits without using memory-heavy string concatenation.
  • Cyber-Physical Foundation: Serving as the foundational building block for controlling relays, motors, and smart factory hardware wirelessly.
